# Longest Word

Given a sentence string, return the longest word in the sentence.

## Word criteria
- Words are separated by a single space
- Only letter (a-z, case-insensitive) count twoard the word's length
- If there are multiple words with the same length, return the first one that appears
- Return the word as it appears in the givcen string, with punctuation removed. 

## Tests
1. "The quick red fox" -> "quick"
2. "Hello coding challenge" -> "challenge"
3. "Do Try This At Home" -> "This"
4. "This sentence... has commas, ellipses, and an exclamation point!" -> "exclamation"
5. "A tie? No way!" -> "tie"
6. "Wouldn't you like to know" -> Wouldnt
