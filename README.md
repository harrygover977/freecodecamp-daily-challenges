# freeCodeCamp Daily Challenges

My solutions to the freeCodeCamp <a href="https://www.freecodecamp.org/learn/daily-coding-challenge/archive">Daily Coding Challenges</a>, one challenge a day, comitted as I go. 

## About

This repo tracks my daily practice. Each day I solve the freeCodeCamp daily challenge and commit my solution here. The goal is consistency: small, steady progress in problem solving and coding fundamentals.
